Conectar Projeto Externo

Utilize o trecho abaixo em seu site, jogo HTML ou aplicativo para conectar diretamente ao mini servidor.

​
const VERO_CONFIG = {
serverId: "server_123",
publicKey: "VERO_LIVE_PUB_XYZ",
endpoint: "https://api.verocloud.io/v1"
};
​
async function savePlayerScore(score) {
const res = await fetch(${VERO_CONFIG.endpoint}/data, {
method: 'POST',
headers: {
'Content-Type': 'application/json',
'X-Server-Id': VERO_CONFIG.serverId,
'X-Public-Key': VERO_CONFIG.publicKey
},
body: JSON.stringify({ collection: 'scores', data: { score, timestamp: Date.now() } })
});
return await res.json();
}

Documentação Oficial da Vero Cloud API

Guia definitivo para integração de mini servidores em sites, jogos e aplicativos.

​

1. Introdução

A Vero Cloud fornece uma camada lógica isolada sobre a infraestrutura do Firebase (Realtime Database e Authentication). Cada usuário possui total autonomia para criar instâncias de mini servidores e gerar chaves de acesso públicas ou privadas.

​

2. Códigos de Erro da API

UNAUTHORIZED: Credenciais ausentes ou inválidas.
INVALID_KEY: Chave de acesso incorreta.
KEY_EXPIRED: A chave utilizada expirou.
PERMISSION_DENIED: Sem permissão para a operação.
SERVER_NOT_FOUND: ID de servidor inexistente.
RATE_LIMIT_EXCEEDED: Limite de requisições excedido.
​

3. Regras de Segurança do Firebase (database.rules.json)

{
"rules": {
"servers": {
"$serverId": {
".read": "auth != null",
".write": "auth != null && data.child('ownerUid').val() === auth.uid"
}
}
}
}
